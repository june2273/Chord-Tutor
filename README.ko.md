# Chord-Tutor

화성학·청음 연습 웹앱이다. 음정, 음계, 조표, 5도권을 MIDI 건반이나 자판, 글자 입력으로 푼다.

## 핵심

- **표기는 MIDI가 아니라 글자에서 쌓는다.** 으뜸음 글자를 한 칸씩 올리고, 목표 음과의 차이를 임시표로 적는다. 그래서 `D E F♯ G A B C♯`가 나온다. 음고류 표로는 원리적으로 못 만드는 표기다.
- **조표는 음고류가 아니라 5도(−7~+7)로 색인한다.** C♭/B, D♭/C♯, G♭/F♯을 따로 담아야 5도권이 닫히는 자리를 가르칠 수 있다.
- **세션은 React를 모르는 상태 기계다.** 채점기와 문제 생성기는 스테이지가 고르는 전략이라, 스테이지를 늘려도 세션 코드는 그대로다.
- 문제 전환마다 200ms 락아웃을 둔다. 직전 문제의 입력이 다음 문제의 답으로 새지 않는다.

## 현황

카탈로그 16개 중 6개가 동작한다. 단일음 청음, 음정, 음계, 조표, 5도권, 가상 피아노다. 테스트는 222개이고, 손으로 적은 표를 규칙과 대조하는 시험이 들어 있다(음정표 92쌍, 음계 48개, 조표 15조).

## 실행

```bash
cd web && npm install && npm run dev
```

MIDI는 Chrome과 Edge에서 된다. 피아노 음원은 [README.md](README.md)의 Run 절을 볼 것.
